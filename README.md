# La Liga de la Parábola

Proyecto de gamificación de Matemática para 3.º y 4.º de secundaria: funciones lineal y cuadrática con baloncesto.
Incluye un simulador de tiros para comprobar parábolas.

Sitio: https://leo87rd.github.io/liga-de-la-parabola/

Medidas de la cancha según International Basketball Federation (2024), *Official basketball rules 2024*.
